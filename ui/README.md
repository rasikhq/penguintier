# penguintier-ui

The small windows of Penguintier (Join Network, About), built with
[Wails v2](https://wails.io) + React + TypeScript and bun. It is a separate
Go module because it needs cgo, GTK 3 and WebKitGTK 4.1, while the rest of
Penguintier is built without cgo.

The tray starts it on demand:

| Command | Result |
|---|---|
| `penguintier-ui join` | Prints the 16-hex-digit network ID on stdout, exit 0. Cancel or close: exit 1. |
| `penguintier-ui about` | Exit 0 when closed. |

Phase P2 owns this directory. See `docs/architecture.md` ("UI process").

## Develop

From the repo root:

```sh
make tools                    # installs the Wails CLI matching go.mod
make ui-dev                   # Join window with hot reload
make ui-dev UI_SCREEN=about   # About window
make ui-build                 # build/bin/penguintier-ui
```

Always build with `-tags webkit2_41` (the Makefile does). `frontend/dist`
is generated, so run `make ui-build` once before `go build` or `go vet` here.

- `main.go`: picks the window from the command line and runs Wails.
- `app.go`: Go methods the frontend calls (`Join`, `Cancel`, `Close`, ...).
- `frontend/src/`: `main.tsx` renders `Join.tsx` or `About.tsx`.
- `frontend/wailsjs/`: TypeScript bindings generated by Wails on each
  build. Don't edit them by hand.
